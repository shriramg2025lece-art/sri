1. Introduction

A DAC converts an N-bit binary word into an analog voltage. The R-2R ladder does this using only two resistor values, R and 2R, so matching is easy in integrated circuits. An op-amp follows the ladder to buffer it (the ladder has Thevenin resistance R and must not be loaded) and optionally to scale it.

Prerequisites: Thevenin/superposition, non-inverting amplifier, voltage follower. Terms: resolution (LSB = Vref/2N), full-scale output, monotonicity, DNL/INL, settling time, glitch.

Design choice. Your question mentions both 3-bit and 4-bit. The simulator below supports both. Default design: 4-bit, Vref = 5 V, R = 10 kΩ, 2R = 20 kΩ, voltage-mode ladder, non-inverting op-amp stage.

Types: weighted-resistor DAC (needs 2N-1 resistor ratio), R-2R voltage-mode (this page), R-2R current-mode / inverted (virtual-ground output), and string (Kelvin-divider) DACs.

3. Working principle and equations

Operation

Looking left from any node, the resistance is 2R: the last node sees 2R (terminator) in parallel with its own 2R branch = R, plus the series R = 2R, and this repeats. So every node has two equal 2R paths, which means each bit's contribution halves as it moves one node toward the LSB. The MSB, closest to the op-amp, contributes Vref/2 at the output.

Derivation (superposition)

Start at the LSB node. Its 2R switch branch (Vref·b0) and the 2R terminator form a divider, giving a Thevenin source Vref·b0/2 behind R. Adding the series R gives 2R, which together with the next 2R switch branch (b1) again forms an equal divider: the previous contribution is halved and b1·Vref/2 is added, still behind R. Repeating up to the MSB node gives VL = Vref(bN-1/2 + bN-2/4 + …), by superposition:

VL = Vref ( bN-1/2 + bN-2/4 + … + b0/2N ) = Vref·D / 2N
Vout = (1 + Rf/Rg)·Vref·D / 2N    (follower: gain = 1)
LSB = Vref/2N  |  VFS(max code) = Vref(1 − 2-N)  |  Rth = R  |  dB = 20 log10(gain)

Variables: D = decimal code (0 to 2N−1), N = bits, Vref in volts, R in ohms. Valid for an ideal op-amp with negligible input current, ideal switches and a ladder not loaded directly. Limits: D = 0 gives 0 V; the output never reaches Vref. For the inverted (current-mode) ladder with virtual ground: Vout = −(Rf/R)·Vref·D/2N.

Practical considerations and misconceptions

  • Gain above 1 needs op-amp supply above the output swing (5 V reference with gain 2 needs more than 9.4 V, not a 5 V rail).
  • Misconception: the output reaches Vref at all-ones. It reaches Vref(1−2-N).
  • Misconception: any resistor error is equal. MSB-side errors dominate, so MSB resistors need the best matching.
  • Switch on-resistance adds to 2R, so use switch widths scaled by bit weight or keep R large relative to Ron.
  • DC vs AC: DC sets the code-to-voltage map. AC (code changes) shows glitches and settling set by op-amp slew rate and bandwidth.

5. Solved problems

Problem 1 (Easy): 4-bit, Vref = 5 V, follower, code 1011. Find Vout.

Formula: Vout = Vref·D/2N. D = 10112 = 11. Vout = 5 V × 11/16 = 3.4375 V. Check by weights: 5(1/2 + 1/8 + 1/16) = 2.5 + 0.625 + 0.3125 = 3.4375 V. It is 11 LSB steps of 0.3125 V.

Problem 2 (Moderate): 3-bit, Vref = 5 V, Rf = Rg. Find the LSB, full scale and Vout for 101.

Ladder LSB = 5/8 = 0.625 V. Gain = 1 + 1 = 2, so output step = 1.25 V. D = 5: Vout = 2 × 5 × 5/8 = 6.25 V. Max (111) = 2 × 5 × 7/8 = 8.75 V. Interpretation: the op-amp supply must exceed 8.75 V plus its headroom.

Problem 3 (GATE-style): a 4-bit R-2R DAC (follower) gives 6.25 V for 1010. Find Vref and the output for 0110.

D = 10: 6.25 = Vref × 10/16 ⇒ Vref = 10 V. For 0110, D = 6: Vout = 10 × 6/16 = 3.75 V. Shortcut: Vout ∝ D, so 6.25 × 6/10 = 3.75 V. LSB = 0.625 V.

7. Core-company interview questions

1. Why R-2R instead of a binary-weighted DAC?Only two values, and a ratio of 2:1 is easy to match on-chip. A weighted DAC needs a 2N-1:1 spread, impractical beyond about 8 bits.
2. Why is the op-amp needed at the output?The ladder has output resistance R. A load RL divides the voltage and causes gain error. The op-amp has high input impedance and low output impedance.
3. Why the extra 2R terminator at the LSB end?It makes every node see 2R to its left, which preserves the binary halving. Without it the LSB weight is wrong.
4. Which bits are most sensitive to resistor mismatch?The MSBs. For monotonicity, MSB error must be below 1 LSB, so it sets the matching requirement.
5. Output is stuck at 0 V for all codes. How do you debug?Check the Vref source, then the switch drive, then the op-amp supplies, then whether + input is shorted to ground and whether the feedback is connected correctly.
6. What causes glitches at 0111 → 1000?All bits flip, and unequal switch delays create a brief wrong code (such as 1111 or 0000). Fixes: deglitch sample-and-hold, low-pass filter, segmented DAC.
7. How do you measure DNL and INL in the lab?Step through every code with a DMM, compute the step minus the ideal LSB (DNL), and compare each output with the best-fit straight line (INL).
8. Voltage-mode vs current-mode (inverted) ladder?In the inverted ladder, node voltages stay near 0 V (virtual ground), so switch resistance matters less and speed is better. The output is inverted: −(Rf/R)VrefD/2N.
9. How does op-amp offset affect the DAC?It adds a constant error (gained by 1+Rf/Rg) at all codes, which shows as zero-code error. Calibrate or choose a low-offset amplifier.
10. Simulation: output looks right at DC but slow on code changes. Why?The op-amp slew rate and bandwidth, the ladder R times the input capacitance, or switch charge. Check the transient settling time to ½ LSB.

Industry view: R-2R ladders appear in waveform generators, trim DACs, audio converters and as the DAC inside SAR ADCs. Teams care about matching, settling and glitch energy.

8. Applications and industry relevance

  • Data acquisition: SAR ADCs use a DAC internally; programmable offset and gain trims.
  • Signal and audio generation: arbitrary waveform output, tone generation on microcontrollers.
  • Control and calibration: setpoint voltages for power supplies and bias generators.
  • Testing challenges: resistor matching, switch resistance, reference noise, glitches.
  • Roles: analog/mixed-signal design, hardware validation, test engineering, embedded hardware.
